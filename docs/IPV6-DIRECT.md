# Прямые IPv6-подключения исключений

## Причина и поведение 0.3.06

При отключённом IPv6 на роутере Ethernet может иметь лишь link-local адрес,
тогда как ProxyBridge-TUN предоставляет компьютеру IPv6-маршрут. Приложения
с кэшированными или встроенными IPv6-адресами всё равно пробуют их использовать.
DNS strategy=ipv4_only не влияет на такие IP-literal подключения.

После DNS hijack и перед маршрутизацией исключений в direct добавлено правило:

1. EXE входит в сохранённые исключения.
2. Назначение IPv6 входит в глобальный диапазон 2000::/3.
3. Default uplink имеет IPv4-адрес.
4. У default uplink нет адреса в 2000::/3 и нет адреса в fc00::/7.

При совпадении sing-box возвращает быстрый отказ (`reject`, `method=default`,
`no_drop=true`), не создавая бесполезное соединение direct. Приложение само
решает, повторять ли запрос по IPv4. Это не преобразование IPv6-only сервиса
в IPv4 и не предоставление отсутствующего IPv6-доступа.

Прочие маршруты, DNS через proxy, native WFP-политика и формат настроек не
меняются. Системный IPv6 и настройки роутера не изменяются. Общий отказ прокси
без VPN на роутере — отдельная неисправность.

## Динамическое условие и границы

Условия выполняет закреплённый sing-box 1.14.4, используя текущий default
interface monitor. Отдельные inverted predicates для GUA и ULA обязательны:
массив default_interface_address означает AND, а не OR. Положительное
условие IPv4 не даёт принять отсутствующий default interface за IPv4-only.
`no_drop=true` сохраняет быстрый отказ при большом числе повторных попыток.

Наличие GUA или ULA отменяет новый отказ, но само по себе не доказывает
доступность IPv6-интернета. Ошибки маршрута/фильтрации в такой сети остаются
видны. ULA и link-local назначения новым правилом не ограничиваются.

Ограничение: default monitor Windows выбирает основной IPv4 uplink.
В сложной конфигурации с IPv4-only default и другим интерфейсом, обслуживающим
доступную глобальную IPv6-подсеть, правило может отклонить это направление.
Такая многосетевая конфигурация этим исправлением не проверена. Обновления
состояния интерфейсов асинхронны; краткое окно устаревших сведений возможно.
