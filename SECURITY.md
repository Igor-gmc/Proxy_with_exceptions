# Конфиденциальные данные

В репозитории нет рабочего профиля прокси. Адрес и учётные данные вводятся
пользователем в приложении. Файлы `.env` приложением не используются и не
должны попадать в Git, даже если созданы для локальных инструментов.

Сохранённый профиль находится в `%LOCALAPPDATA%\ProxyBridge\settings.dat`,
зашифрован Windows DPAPI и ограничен правами доступа. Зашифрованные файлы
настроек также нельзя публиковать. Во время работы движку нужен временный
конфиг с реквизитами: он хранится в защищённом каталоге компонентов и удаляется
при штатной остановке. После аварии возможно наличие остаточного файла.

Журналы и отчёты содержат IP-адреса, пути программ, сведения об интерфейсах
и пользовательские заметки. Маскирование паролей не делает журнал публичным.
Перед созданием issue подготовьте минимальное обезличенное описание ошибки.
Не прикладывайте исходные журналы, дампы, настройки, VPN-профили и ключи.

Перед отправкой изменений:

```powershell
git diff --cached --stat
python tools/check-publication.py --staged
```

Проверка дополняет ручной просмотр: она блокирует опасные имена файлов,
исполняемые артефакты и распространённые форматы секретов, но не гарантирует
обнаружение произвольного пароля. Не используйте `git add -f` для обхода правил.
Если секрет уже попал в историю или удалённый репозиторий, его необходимо
отозвать/заменить; удаления из последнего коммита недостаточно.
