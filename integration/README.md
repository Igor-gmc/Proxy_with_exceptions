# Интеграционные проверки

Этот стенд предназначен для ручной диагностики на Windows x64. Он не запускается
сборкой и не предназначен для фоновой работы. Некоторые команды запускают TUN,
меняют собственную политику WFP, используют рабочий профиль и посылают реальный
трафик. Выполняйте только осознанно, по одной проверке, при закрытом GUI и с
возможностью локального восстановления интернета.

```powershell
dotnet build integration/ProxyBridge.Integration.csproj -c Release -o artifacts/integration-bin
```

Проверки требуют прав администратора. Каталог результата должен быть новым
и абсолютным. Аргументы команд и предусловия определены в Program.cs; перед
живым испытанием проверьте их для выбранного сценария. Интерфейс и профиль
нельзя брать из чужого отчёта. Учётные данные не передавайте в командной строке.

## Сбор активности без рабочего туннеля

```powershell
.\artifacts\integration-bin\ProxyBridge.Integration.exe --activity-test D:\Reports\NewActivityRun
```

Запускает собственный дочерний процесс с loopback TCP/UDP и проверяет ETW.
Не меняет WFP, TUN, DNS или маршруты. При конфликте с существующей ETW-сессией
отказывается работать, не останавливая чужую сессию.

## Живые сетевые сценарии

В исходниках доступны incident, connection-path, destination, production-soak
и production-load проверки. Они не являются универсальным тестом безопасности.
Сохранённый профиль должен быть настроен пользователем; встроенных реквизитов
нет. Отсутствие профиля — повод остановить проверку, а не подставить чужой сервер.

Перед испытанием запишите ожидаемые маршруты, состояние защиты и приложения
в исключениях. Не запускайте два сетевых теста одновременно и не отключайте
антивирус. Восстановление должно удалять только фильтры, которыми владел тест.

## Конфиденциальность результатов

Отчёты содержат адреса, пути, характеристики интерфейсов и сетевые события.
Сохраняйте их локально вне Git. В публичное issue переносите только минимальные
обезличенные сведения. PASS отдельного HTTPS-запроса или проверки политики
не доказывает отсутствие DNS/UDP/IPv6 утечек или корректность всех аварийных
сценариев. Исторические протоколы личной среды в репозиторий не включены.
